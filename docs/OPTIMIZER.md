# Оптимизатор цены

Инструмент, который помогает ответить на вопрос:
**«По какой цене продавать?»**

## Зачем

Заказчик знает:
- Закупочную цену.
- Текущий спрос (сколько продаётся сейчас).
- Текущую цену продажи.

Но не знает:
- Как изменится спрос при изменении цены.
- При какой цене прибыль максимальна.

Оптимизатор **перебирает** возможные цены и находит **оптимум**.

## Как работает

### Эластичность спроса

Ключевой параметр — **эластичность (E)**. Она показывает,
на сколько процентов изменится спрос при изменении цены на 1%.

| E | Что значит |
|---|------------|
| 0 | Спрос не реагирует на цену |
| 0.5 | Слабая реакция: цена +10% → спрос −5% |
| 1.0 | Пропорционально: цена +10% → спрос −10% |
| 1.5 | Сильная: цена +10% → спрос −15% |

**По умолчанию** в программе **E = 0.8**.

### Формулы

При изменении цены на Δ%:

    Новая цена     = Текущая × (1 + Δ/100)
    Новый спрос    = Текущий × (1 − E × Δ/100)
    Новая прибыль  = (Новая цена − Закупка) × Новый спрос

### Перебор

Оптимизатор перебирает Δ от **−20%** до **+40%** с шагом **1%**.
Для каждого Δ считает прибыль. Находит **максимум**.

## Что видит заказчик

### Вкладка «Что-если»

Таблица с прогнозом по каждому товару:

| Товар | Текущая | Новая | Δ% | Продажа | Прибыль | Δ прибыли |
|-------|---------|-------|-----|---------|---------|-----------|
| Чипсы | 110 | **130** | +18.2% | 100 → 82 | 5500 → 6150 | +650 |

Внизу — **суммарная прибыль** кафе.

### Кнопки

- **💡 Найти оптимум** — подставляет оптимальные цены для всех товаров.
- **✏️ Изменить цену товара** — вводит новую цену вручную.
- **↺ Сбросить к текущим** — возвращает цены к исходным.

### График `chart_optimal.png`

Создаётся при сохранении отчёта. Показывает:
- **Кривую** — прибыль при разном Δ%.
- **Красную точку** — оптимум.
- **Серую вертикаль** — текущая цена (Δ=0).

## Как читать результат

Если оптимум **справа от 0** — можно **поднять** цену.
Если **слева** — цену лучше **снизить**.
Если **на 0** — текущая цена уже оптимальна.

**Пример:**

> Текущая цена: 110 ₽.
> Оптимум: +18% = 130 ₽.
> Прибыль вырастет с 5500 ₽ до 6150 ₽ (+650 ₽).

## Параметры командной строки

Эластичность задаётся в GUI (вкладка «Настройки»):

- **0** — спрос не реагирует (нет смысла снижать цену).
- **0.5** — слабая эластичность (продукты питания).
- **1.0** — пропорционально (стандарт для розницы).
- **1.5+** — сильная (импульсные покупки).

## Ограничения

**Модель линейная.** Если цена меняется на ±30–40%, реальный спрос
может падать **быстрее**, чем предсказывает формула.

**Нет конкуренции.** Не учитывается, что рядом может быть другое кафе
с более низкими ценами.

**Нет порога отсечения.** При цене 500 ₽ за кофе модель всё равно
посчитает «продадим N чашек» — хотя в реальности не продадите.

**Вывод:** оптимизатор — **ориентир**, а не точный прогноз.
Для малых шагов (±5–15%) модель достаточно надёжна.
