# Импорт данных из внешних систем

Программа умеет принимать выгрузки из **1С**, **iiko**, **R-Keeper**
и любых других систем — если они выгружают данные в **xlsx** или **csv**.

## Зачем это нужно

Обычно заказчик уже ведёт учёт в своей системе. Вручную переносить
данные в `cafe_data.xlsx` — долго и с ошибками. Импортёр делает это
**автоматически**.

## Как это работает

### Первый импорт — диалог

Запускаете:

    python tools/import_external.py --input выгрузка.xlsx

Программа:

1. Читает файл.
2. Показывает список столбцов.
3. Спрашивает у вас, какой столбец чему соответствует.
4. Запоминает маппинг в `tools/mappings.json`.
5. Преобразует данные в формат `cafe_data.xlsx`.

**Диалог занимает 1–2 минуты.** Вы вводите номера или имена столбцов:

    Поле «Товар» — Название товара [подсказка: Наименование]
    > 1

    Поле «Цена_1» — Цена продажи в 1 периоде [подсказка: Цена]
    > 4

Для необязательных полей можно нажать **Enter** и пропустить.

### Повторный импорт — без диалога

Если вы импортируете файл с **той же структурой** столбцов — программа
**узнаёт** формат по сигнатуре и применяет сохранённый маппинг. Диалога
**не будет**.

    python tools/import_external.py --input выгрузка_2.xlsx
    > Найден сохранённый маппинг: 1С:Общепит
    > Преобразую данные...
    > Готово: cafe_data.xlsx

### Если заказчик сменил программу

Столбцы в новой выгрузке другие → программа **снова спросит** маппинг.
Старый маппинг **сохранится** — при возврате к первой системе
программа его **вспомнит**.

## Параметры командной строки

| Флаг | Что делает |
|------|-----------|
| `--input ФАЙЛ` | Обязательный. Путь к выгрузке (.xlsx, .xls, .csv) |
| `--out ФАЙЛ` | Куда сохранить (по умолчанию `cafe_data.xlsx`) |
| `--no-collapse` | Не сворачивать дубликаты |

## Сворачивание дубликатов

Если выгрузка содержит **несколько строк на один товар** (например,
продажи по дням):

| Дата | Товар | Кол-во |
|------|-------|--------|
| 2026-01-01 | Чипсы | 5 |
| 2026-01-02 | Чипсы | 7 |

Программа **суммирует** по товару → в результате одна строка:

| Товар | Кол_1 |
|-------|-------|
| Чипсы | 12 |

По умолчанию сворачивание **включено**. Отключить: `--no-collapse`.

## Где хранятся маппинги

Файл `tools/mappings.json`. Формат:

    {
      "mappings": [
        {
          "signature": "abc123...",
          "name": "1С:Общепит v11",
          "columns": ["Артикул", "Наименование", ...],
          "mapping": {
            "Товар": "Наименование",
            "Цена_1": "Цена",
            ...
          }
        }
      ]
    }

**Файл можно редактировать вручную** — если что-то пошло не так.
Или удалить — при следующем импорте диалог появится снова.

## Пример

Файл `docs/examples/sample_1c_export.xlsx` — пример выгрузки из 1С.

Импорт:

    python tools/import_external.py --input docs/examples/sample_1c_export.xlsx

Программа покажет столбцы:

    [0] Артикул
    [1] Наименование
    [2] Категория
    [3] Закуп.Цена
    [4] Цена
    [5] Кол-во

Дальше — по шагам отвечаете на вопросы.
